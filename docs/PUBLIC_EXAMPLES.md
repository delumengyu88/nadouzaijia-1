# 首页示例公开授权

首页和示例详情允许匿名访问。采用正式项目数据时，一条示例需要权利方明确授权公开该条报告中的节目名、平台、网络、检测日期、类别、帧数和时间点。只有摘要或会员查询授权的内容继续使用原有分层。管理员在工作台选择节目和上下线，公开授权由运维按已有权利凭证录入。

## 录入一条已有授权

1. 在项目的已核导入记录中确认任务 ID、规范节目名、索引行 ID 和已核片单的 SHA-256。核对权利文件覆盖这条记录及匿名报告字段。将权利文件留在私有运维目录并计算 SHA-256。
2. 在同一私有目录准备 JSON 清单，填入以下字段。原文件及清单均不随代码、前端包或报告发布。

| 字段 | 内容 |
| --- | --- |
| `scope` | `anonymous_home_example_detail` |
| `task_id`、`program`、`record_id` | 精确任务、规范节目名和索引行 ID |
| `source_sha256` | 已核片单的 SHA-256 |
| `permission_sha256` | 本条匿名展示权利文件的 SHA-256 |

3. 在已部署的项目服务环境先运行 `python -m nadou public-example-permit --manifest <清单> --permission-file <权利文件>`。检查通过后，在同一命令末尾加 `--apply` 录入单行许可。重复录入相同有效许可保留现有发布。
4. 管理员进入工作台「内容配置 → 首页示例记录」，选择该记录并点「添加示例」，或在旧配置上点「确认发布」。用匿名首页和该节目的示例详情核验。达到 5 条上线配置时可先下线一条，历史记录仍保留。

撤销时运行 `python -m nadou public-example-permit --revoke-record <行ID>` 检查，再加 `--apply`。匿名首页与详情在下次读取时停止展示。将来重新获得许可后，工作台需重新发布。未产生过公开许可的环境可回退 0020；已有许可记录的数据库会阻止删除许可表。
