# 那豆在架小程序

原生微信小程序，目录就是本文件夹。默认使用本地假数据，不连接服务器也能走完查询、报告、支付、邀请码和取证。

## 导入微信开发者工具

1. 安装微信开发者工具（稳定版）。
2. 选择「导入项目」。
3. 目录选中本仓库里的 `miniprogram` 文件夹，不要选仓库根目录。
4. AppID 保持 `touristappid`，使用测试号或游客模式。不要把正式 AppID 写回仓库。
5. 本地设置里关闭「校验合法域名」。连自己的后端时也要先关掉，否则请求会被拦截。
6. 编译。入口是首页。第一次打开会看到开屏，右下角「跳过」后进入首页。开屏、公告和查询完成都盖在完整首页上，底部标签在遮罩下面。

底部标签只有三项：首页、会员中心、个人中心。

## 本地数据与后端

开关在 `config.js`：

- `useMock: true`：使用 `api/mock.js`，不访问网络。验收和演示用这个。
- `useMock: false`：使用 `api/http.js`。把 `apiBase` 改成你自己的服务根地址，不要提交真实地址。检索请求是 `GET /api/v1/programs/search?name=`，请求头 `X-User-Id`。返回体会按同一套字段整理；锁定记录只保留编号、年龄档和锁定原因。

后端骨架目前只提供检索。关掉本地数据后，订单、邀请码和取证会提示服务暂不可用。

## 演示账号

个人中心底部「切换账号」：

| 账号 | 能看到什么 |
| --- | --- |
| 未登录 | 首页游客提示。开始查询会先要求登录。 |
| 免费用户 | 报告里的记录是毛玻璃，只显示条数、日期和「涉及 N 个平台」。 |
| 会员 | 已开通 VIP，同时有一段普通会员，两段同时计时。取证申请、订单和查询记录都有样例。 |

邀请码在免费用户下兑换。每个账号只能绑定一次。码为 8 位大写字母或数字，去掉了易混字符。

| 输入 | 结果 |
| --- | --- |
| `A8K3N2P7` | 成功，发放普通会员 30 天 |
| `B7C4D6E8` | 无效 |
| `C9D5E7F2` | 已过期 |
| `D4E6F8G3` | 已被使用 |
| 已绑定后再填 | 不能再填 |

若该账号已经是 VIP，成功页会写明与 VIP 同时计时。连续输错 5 次后锁定 1 小时。

支付没有商户号，支付页用结果按钮代替微信支付弹窗。支付失败后主按钮是「查看订单状态」。确认未支付后才出现「重新支付」，订单号不变。

建议演示顺序：首页输入下面四行，开始查询，确认后看结果。

```
星河旧梦
长街烟火
雾港来信
南岭追光
```

`南岭追光` 第一次会失败，可单条重试。会员账号的取证列表里有失败并已全额退款的一单。

## 还缺的外部条件

- 正式小程序 AppID（现在是游客号）
- ICP 备案通过后才能上线
- 一台自有服务器，以及已备案的 https 域名
- 微信支付商户号和虚拟支付权限
- 只读数据账号与授权
- 画面校准数据

这些都不要写进仓库。
